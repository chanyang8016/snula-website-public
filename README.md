# SNU 조경학전공 홈페이지 리뉴얼 — 공개용 작업 기록

서울대학교 조경학전공 홈페이지(WordPress + Elementor) 리뉴얼 과정의 **설계 결정·구현 방식·위젯 소스**를 정리한 공개용 저장소입니다.
운영 관련 정보(계정, 로그인 경로, 보안장비, 내부 연락처, 개인 데이터)는 제거하거나 `<placeholder>`로 치환했습니다.

## 구성

| 경로 | 내용 |
|---|---|
| `docs/작업정리_통합.md` | 사이트 구조(페이지·위젯 ID), 전역 CSS 블록 구조, 디자인 시스템, 편집 워크플로, 페이지별 변경 이력 |
| `docs/작업정리_20260907_SNUDOLA세션.md` | SNU DOLA 메뉴 작업 기록 |
| `widgets/` | 홈 테마(`home_theme.html`), 히어로, 연혁 연표, 학부·대학원 과정, 졸업생진로 그래프, Research 논문 브라우저 위젯 소스 (HTML/CSS/JS) |
| `css/` | 전역 CSS(킷) 스냅샷, 게시판 글쓰기 화면 다크 테마 |
| `tools/` | 편집 보조 스크립트 (로컬 페이로드 서버, 레이아웃 스캐너) |

## 기술 메모

- Elementor 편집기 콘솔에서 `$e.run('document/elements/settings', …)` + `document/save/default`로 위젯을 프로그래밍 방식으로 수정했습니다.
- 전역 스타일은 킷(Default Kit) `custom_css`에 `/* SNULA-XXX vN START/END */` 마커 블록 단위로 관리했습니다.
- 위젯 내 JS에서 `&&`는 저장 시 HTML 엔티티로 변환되어 깨지므로 중첩 `if`로 풀어 썼습니다.
- 디자인: 웜 블랙 `#1e1b17` + 크림 `#edeae3`, 포인트 흙색 `#BE8134`, Helvetica/Noto Sans KR.

## 제외된 것

Research 위젯의 학위논문 데이터(저자·지도교수 명단), 사진 선별 리포트, 인수인계용 운영 문서, 관리자 계정·로그인 경로·보안장비 관련 내용.
