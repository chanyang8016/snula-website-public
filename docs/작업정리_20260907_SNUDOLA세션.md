## 통합본 §6에 추가할 함정
- Elementor 페이지 래퍼 `.elementor-N{overflow:hidden}`이 스크롤 컨테이너가 되어 `scroll-snap`이 뷰포트에 안 걸림 → 해당 페이지에서 `body.page-id-N .elementor-N{overflow:visible !important}`.
- 페이지 CSS(`post-N.css`)가 `.elementor-N .elementor-widget-text-editor h3{color:… !important}`로 제목 색을 고정 → 밴드별 색은 `.elementor-N .elementor-widget-text-editor .hs3 …{color:var(--ink) !important}`로 이겨야 함.
- 풀블리드 밴드는 콘텐츠 열이 화면 중앙이 아니므로 JS로 `--bx/--bw` 실측(`fitBands`).
- 스냅 페이지에서 `scroll-behavior:smooth`는 빼는 게 안정적(스냅 자체가 애니메이션됨). 검증 시 scrollY 판독이 수 초 늦으니 5초 이상 기다릴 것.
- 확장 프로그램의 ref 클릭은 scrollIntoView를 먼저 하므로 스냅 페이지 검증은 좌표 클릭/실제 휠로.
